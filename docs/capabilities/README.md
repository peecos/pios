# PIOS Capability Library

The PIOS Capability Library preserves reusable capability meaning alongside the PIOS architecture. It extracts durable requirements from admitted design sources without turning historical applications, screens, endpoints, tables, or implementation choices into the definition of PIOS itself.

Capability documents version independently. Inclusion in this repository does not automatically make a capability mandatory for the Core contract, adopt it into a compatibility level, prove an implementation, or determine where it must run.

The initial pilot covers governed content retention and derivation, context allocation, retrieval context assembly, conversation consolidation, proposals, and standing rules. Phase 2 now includes knowledge/context; action and execution; event and History; source/import governance; operational inspection; portability and recovery; cutover, decommissioning, erasure, connector reauthorization; governed capture with pending-work reconciliation; onboarding and first entry; personal-AI identity/preferences; Role, Mode, active-context, and outward-representation governance; observed-pattern detection and lifecycle evaluation; direction and success objects; controlled sharing, public publication, access, discoverability, and usage-rights governance; structured reviews with reflective assessments; human contacts, contact points, verification, and relationship context; agent definitions, runtime roles, synchronization, outward identity, and representative conversation; collaboration channels, work-linked threads, attributed messages, and task-scoped execution workspaces; personal conversation continuity with governed owner access paths; device-local caching, deliberate offline availability, and personal reading queues; operation cost estimation, resource reservation, and usage reconciliation; candidate source discovery, owner implementation documentation, and knowledge-integrity assessment; personal Meaning, evidence-linked Learning, and derived-representation lifecycle governance; and explicit promotion of accepted working artifacts into canonical state.
