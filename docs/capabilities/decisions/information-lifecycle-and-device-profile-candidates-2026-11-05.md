## Profile work that does not need new CRDs here

- Apple-local storage, optional cloud replication, connector implementations
  and browser access are proposed realization choices in the
  [device profile](../../apple-local-and-mixed-device-profile-v0.1.md).
- Mixed-device examples and capability-led adoption explain configuration and
  product use; they do not add another Core Compatibility Level.
- Shared-result reuse and controlled disclosure use current grants and source
  lineage. No new authority namespace or universal model is introduced.
